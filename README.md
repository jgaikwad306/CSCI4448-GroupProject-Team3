We used 3 Design Patterns for this Project

Design patterns
*Observer- The observer pattern takes the actual gameplay code and
and sends it to the gui through an updateObservers function


*Builder- Every new game of sudoku is built using a builder pattern 
that chains optional settings


*Strategy- A user selects their difficulty in the game using a Strategy pattern that 
that removes and adds cells based on the difficulty chosen.

We also added 5 tests 1 for the difficulty, 1 for gameplay, and 2 for the observers
